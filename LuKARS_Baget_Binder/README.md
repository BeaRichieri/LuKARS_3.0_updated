# LuKARS Baget student exercise

This repository contains the simplified LuKARS Baget exercise for students.

## Run online with Binder

Use the Binder launch link generated for this repository at https://mybinder.org/.

## Files

- `LuKARS3.0_Baget.ipynb` — student Jupyter notebook
- `lukars_model.py` — LuKARS model functions
- `input.txt` — input time series
- `binder/requirements.txt` — Python dependencies
- `binder/runtime.txt` — Python runtime used by Binder

The notebook and its supporting files must remain in the same repository directory.
