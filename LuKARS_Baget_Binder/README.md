# LuKARS Baget student exercise

This repository contains the simplified **LuKARS Baget exercise** for students.

The exercise can be run entirely online with **Binder**, so no local installation of Python, Jupyter, or Anaconda is required.

## Run the exercise online with Binder

Go to [mybinder.org](https://mybinder.org/) and enter the following information:

- **Repository provider:** GitHub
- **GitHub repository name or URL:** `BeaRichieri/LuKARS_3.0_updated`
- **Git ref (branch, tag, or commit):** `HEAD`
- **File to open (in JupyterLab):** `LuKARS_Baget_Binder/LuKARS3.0_Baget.ipynb`

Then click **Launch**. Binder will build the required Python environment and open the LuKARS notebook directly in JupyterLab.

### Direct notebook link

You can also open the exercise directly using this link:

[Launch LuKARS Baget in Binder](https://mybinder.org/v2/gh/BeaRichieri/LuKARS_3.0_updated/HEAD?urlpath=%2Fdoc%2Ftree%2FLuKARS_Baget_Binder%2FLuKARS3.0_Baget.ipynb)

> **Note for students:** Binder sessions are temporary. If you modify the notebook and want to keep your work, download the notebook before closing the session.

## Files

- `LuKARS3.0_Baget.ipynb` — student Jupyter notebook
- `lukars_model.py` — LuKARS model functions
- `input.txt` — input time series

The notebook, `lukars_model.py`, and `input.txt` must remain in the same directory so that the notebook can import the model functions and read the input data correctly.
